The essentials, in familiar clothes

Old-school interface.
Real browser features.

Not a screenshot or a fake desktop. Web98 is a desktop application designed to open real websites, manage tabs, and keep everyday browsing tools close at hand.

▤

Browse for real

Open live websites in browser tabs, navigate back and forward, reload pages, and see loading status.

★

Your places, saved

Keep favorites in folders, revisit browsing history, and use address-bar suggestions to get back faster.

↓

Downloads, managed

Track downloads, monitor progress, choose a destination folder, and confirm before opening completed files.

⌕

Find what you need

Search within a page, use keyboard shortcuts, and reach common commands through classic menus.

⚙

Make it yours

Set a homepage, choose a search provider, adjust text size, and configure download preferences.

▣

A desktop-native feel

Window chrome, task buttons, dialogs, and menus take cues from the classic Windows desktop era.

The idea behind Web98

Made for nostalgia.
Built as software.

The visual language comes from the late 1990s. Underneath, Web98 uses a modern browser engine and a security-conscious application architecture.
