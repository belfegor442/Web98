About permissions
Camera, microphone, geolocation, notifications and similar features are denied unless you grant them here. The address bar shows zone and security state for the current page.
Certificates
Web98 uses the system certificate store. Pages with invalid certificates show an error screen where you can explicitly continue at your own risk.
Pop-ups
Prevents pages from opening new windows without your interaction.
Personal information
Web98 can fill forms with this information when you press Ctrl+Shift+F on a page. Data never leaves your computer.
Web98 engine

Interface: native Win32 + HTML/CSS chrome
Storage: SQLite (favorites, history, cookies, settings)
